🥗 HealthyPredict
📌 Descrição do Projeto

O HealthyPredict é uma plataforma web que utiliza Inteligência Artificial para identificar alimentos a partir de imagens, gerar automaticamente a tabela nutricional correspondente e criar rotinas alimentares personalizadas.
O sistema foi desenvolvido com uma IA própria, integrada ao backend, com foco em saúde, nutrição e tecnologia.

🎯 Objetivo

Facilitar o controle alimentar e auxiliar usuários na criação de hábitos mais saudáveis, utilizando tecnologia de Visão Computacional e Análise Nutricional automatizada.

⚙️ Funcionalidades

- Upload de imagens de alimentos
- Identificação automática do alimento utilizando IA
- Geração da tabela nutricional do alimento identificado
- Criação de rotinas alimentares personalizadas
- Interface web simples e intuitiva
- Backend integrado com modelo de IA próprio

🧠 Inteligência Artificial

-Modelo de IA desenvolvido para reconhecimento de alimentos a partir de imagens
-Processamento e classificação realizados em Python
-Integração da IA com o backend da aplicação

🏗️ Arquitetura

-Frontend: HTML e JavaScript
-Backend: Java
-IA / Processamento de Imagens: Python
-Containerização: Docker
-Versionamento: Git e GitLab
A aplicação foi organizada de forma modular, facilitando manutenção, escalabilidade e futuras melhorias.
